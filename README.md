# 🍦 Meridian Ice Cream Sales Dashboard

## 📊 Project Overview

An interactive Power BI dashboard developed for Meridian Ice Cream to analyze sales performance, customer behavior, product performance and outlet performance.

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-selling ice cream flavors
- Compare outlet performance
- Analyze customer age groups
- Understand payment method distribution
- Analyze monthly sales trends
- Study the relationship between temperature and sales

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Microsoft Excel
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

- Total Sales
- Average Bill
- Total Orders
- Average Customer Rating
- Monthly Sales Trend
- Sales by Category
- Sales by Flavor
- Sales by Outlet
- Payment Mode Distribution
- Customer Age Group Analysis
- Weather vs Sales Analysis
- Interactive Filters

## 📂 Dataset

The dataset contains 10,000 sales records with information about:

- Orders
- Customers
- Products
- Flavors
- Categories
- Outlets
- Cities
- Payment Methods
- Ratings
- Temperature
- Weather
- Sales
- Discounts
